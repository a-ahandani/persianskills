# University of Tehran Overlay

Use this overlay only for a University of Tehran thesis/dissertation project.

## Authority rule

1. Locate the current university-wide thesis/dissertation guide.
2. Record its title, publication/approval date, and local file path in the project profile.
3. Locate any faculty, campus, department, or degree-specific supplement.
4. Record supervisor-approved deviations.
5. Apply the most specific current rule that validly controls the manuscript.

University of Tehran library/faculty pages currently point to a university-wide guide from **Aban 1403 (October–November 2024)**. Reverify this date and document at project start because institutional guidance can change.

## How to use `sinamomken/tehran-thesis`

The repository documents a template based on a **September 2013** University of Tehran guide. Use it as:

- a modular XePersian implementation example;
- a glossary/English–Persian terminology pattern;
- a source of useful chapter-function guidance;
- a reminder to inspect bibliography, glossary, figures, and recursive chapter files.

Do not use it as authority for:

- current cover/front-matter layout;
- fonts, margins, spacing, page numbering, or binding rules;
- required chapter count/order;
- page-count recommendations;
- citation style;
- literature recency;
- package/tool versions.

## Editorial extraction from the repository

Retain these rhetorical functions:

- Introduction: problem, importance, motivation, research questions, brief approach, roadmap.
- Literature review: classify/synthesize work, identify gaps, position the study.
- Methodology: justify choices, make the study reproducible/auditable, explain validation.
- Results: present findings that answer the research questions.
- Discussion/conclusion: interpret against evidence/literature; avoid speculation and overgeneralization; state contribution, implications, limitations, and future work without new evidence.

Convert these into checks. Do not force the repository’s sample wording or chapter lengths.

## UT review checklist

Before final QC, verify against the attached current guide:

- required front and back matter;
- Persian and English title/abstract pages;
- order and naming of lists;
- fonts and sizes;
- margins, line spacing, paragraph indentation;
- page-numbering regions;
- chapter/section numbering;
- figure/table/equation caption and numbering rules;
- citation/bibliography requirements;
- glossary/index requirements;
- electronic submission and file rules;
- faculty-specific forms and approvals.

Do not fill unknown values from memory or from the 2013 template.
