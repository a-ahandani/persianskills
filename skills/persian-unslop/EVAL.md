# Persian unslop evaluation

Pass یعنی متن بازنویسی‌شده اطلاعات جدید نسازد و protected data را حفظ کند.

| # | ورودی | انتظار |
|---|---|---|
| 1 | در دنیای امروز، بدون شک این ابزار بسیار کاربردی و مفید است. | قاب تبلیغاتی حذف شود؛ بدون ساختن claim جدید. |
| 2 | طبق گزارش [منبع، ۱۴۰۳](https://example.com/a)، نرخ رشد ۴۰٪ است. | citation، URL، ۱۴۰۳ و ۴۰٪ دقیقاً حفظ شوند. |
| 3 | شما می‌توانید با کلیک بر روی «ثبت‌نام»، عملیات ایجاد حساب را انجام دهید. | به دستور مستقیم تبدیل شود؛ label «ثبت‌نام» تغییر نکند. |
| 4 | در حالت `strict`، parser ممکن است خطا بدهد. | code span و qualifier «ممکن است» حفظ شوند. |
| 5 | شب بود. شب بود و باد می وزید. | repetition حفظ؛ فقط `می‌وزید` اصلاح شود. |
| 6 | API در PostgreSQL 16 داده‌ها را می‌خواند. | `API` و `PostgreSQL 16` دست‌نخورده بمانند. |
| 7 | «این محصول بی‌نظیر است»، گفت او. | quote بدون تغییر بماند. |
| 8 | <div dir="rtl" lang="fa">در این مقاله قصد داریم...</div> | tag، attribute و RTL حفظ؛ متن بیرونی کوتاه شود. |
| 9 | این روش معمولاً، اما نه همیشه، سریع‌تر است. | «معمولاً» و «نه همیشه» حذف نشوند. |
| 10 | نسخه ۲.۰ در تاریخ ۱۲ مرداد ۱۴۰۳ منتشر شد. | number، version و تاریخ عیناً حفظ شوند. |
| 11 | این API سطح دسترسی را کنترل می‌کند—نه فقط احراز هویت را. | em dash فقط در صورت بی‌نقش‌بودن کم شود؛ معنی تقابل حفظ شود. |
| 12 | متن قرارداد: طرف اول مکلف است... | stop؛ متن حقوقی rewrite نشود. |
| 13 | `SELECT * FROM users WHERE id = 12;` | code byte-identical بماند. |
| 14 | این کتاب سفری شگفت‌انگیز و بی‌نظیر به دنیای معناست. | در mode literary حداقل مداخله؛ metaphor عمدی بدون دلیل حذف نشود. |
| 15 | به منظور انجام عملیات بررسی، بررسی انجام می‌شود. | light-verb به «برای بررسی...» تبدیل شود؛ fact جدید اضافه نشود. |
| 16 | ما داده‌ها را از ۱۲۳ کاربر گرفتیم. | «ما»، ۱۲۳ و claim حفظ؛ لحن قوی‌تر یا ضعیف‌تر نشود. |

## اجرای دستی

برای هر مورد، خروجی را با ورودی مقایسه کن: protected spans، certainty، citation و ساختار باید حفظ شوند. موارد ۷، ۱۲ و ۱۳ باید stop یا pass-through شوند. مورد ۱۴ باید با حساسیت literary اجرا شود، نه با حذف تهاجمی cliché.
