# Draft queue of Latin terms awaiting approval
#
# `check_persian.py --pending` fills this file, and it deliberately has no
# effect on checking messages. A term is not accepted in any message until
# you move it to allowlist.txt by hand.
#
# How to approve: for each line, decide whether it really has to stay in
# Latin or whether a Persian transliteration or explanation would do. Move
# the approved items to allowlist.txt with the reason as a comment next to
# each one. Delete the rest from here.
#
# Warning: allowlist.txt is a way around the check. The longer it gets, the
# more likely an unnecessary Latin word slips past the flags unnoticed.
# That is why `--strict` is required in the final step.
